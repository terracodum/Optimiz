# Лабораторная работа 4 — Многокритериальная оптимизация (Парето)

Три метода построения множества Парето при минимизации нескольких критериев одновременно.

Все методы принимают произвольный кортеж `funcs` — работают с любым числом критериев.

**Вариант 1 (пример запуска)** — три критерия вида `fi(x1, x2) = ai·(x1−bi)² + ci·(x2−di)²`:

| Критерий | a | b  | c | d  | Безусловный min |
|----------|---|----|---|----|-----------------|
| f1       | 2 | 6  | 3 | 6  | (6, 6)          |
| f2       | 3 | −4 | 1 | −6 | (−4, −6)        |
| f3       | 1 | −7 | 2 | 8  | (−7, 8)         |

## lab4.py — главный файл

```python
def f1(x): return 2*(x[0]-6)**2  + 3*(x[1]-6)**2
def f2(x): return 3*(x[0]+4)**2  + 1*(x[1]+6)**2
def f3(x): return 1*(x[0]+7)**2  + 2*(x[1]-8)**2

funcs = (f1, f2, f3)

pts_add  = additive_pareto(funcs)
pts_disc = discriminant_pareto(funcs)
pts_succ = successive_pareto(funcs)
```

Чтобы передать другие критерии — замени функции и собери их в кортеж `funcs`.

## additive.py — метод аддитивной свертки

### Идея

Все критерии объединяются в один: `F = α₁·f₁ + α₂·f₂ + … + αₙ·fₙ → min`, где `αᵢ ≥ 0` и `Σαᵢ = 1`. Меняя веса, мы получаем разные точки Парето: при `αᵢ = 1` — безусловный минимум i-го критерия, при равных весах — компромисс.

### Как работает

1. Генерируется `n_points` наборов весов: первые `n` — угловые (один критерий с весом 1, остальные 0), остаток — случайные выборки из распределения Дирихле (фиксированный seed).
2. Для каждого набора весов строится сводная функция `F = Σ αⱼ·fⱼ(x)`.
3. `F` минимизируется методом Нелдера-Мида (не требует градиентов).
4. Найденная точка добавляется в множество Парето.

### Ключевые строки

```python
n = len(funcs)
weights[i][i] = 1.0                                  # угловая точка для i-го критерия
weights[n:] = rng.dirichlet(np.ones(n), size=...)    # случайные внутренние веса

F = lambda x, w=w: sum(w[j] * funcs[j](x) for j in range(n))
res = minimize(F, [0.0, 0.0], method='Nelder-Mead')
```

## discrim.py — дискриминационный метод

### Идея

Выбирается один главный критерий (последний в `funcs`), а на остальные накладываются ограничения-уступки: `fⱼ(x) ≤ limⱼ`. Варьируя строгость ограничений — от жёстких до мягких — получаем разные Парето-точки.

### Как работает

1. Находятся безусловные минимумы всех функций кроме последней.
2. Для каждой из них строится диапазон ограничений `linspace(fmin + 20, fmin + 500, n_points)`.
3. На каждой итерации минимизируется `funcs[-1]` методом SLSQP при активных ограничениях `fⱼ(x) ≤ limⱼ`.
4. **Жёсткие lim:** минимизатор вынужден оставаться близко к минимумам первых критериев — компромиссная точка. **Мягкие lim:** ограничения не активны, точка уходит к безусловному минимуму `funcs[-1]`.

### Ключевые строки

```python
n = len(funcs)
f_mins = [fi(minimize(fi, ...).x) for fi in funcs[:-1]]
lim_ranges = [np.linspace(fmin + 20, fmin + 500, n_points) for fmin in f_mins]

constraints = [
    {'type': 'ineq', 'fun': lambda x, fi=funcs[j], l=lim_ranges[j][i]: l - fi(x)}
    for j in range(n - 1)
]
res = minimize(funcs[-1], [0.0, 0.0], method='SLSQP', constraints=constraints)
```

## successive.py — метод последовательных уступок

### Идея

Критерии оптимизируются последовательно по приоритету: сначала важнейший, потом каждый следующий — с ограничением, что предыдущий ухудшается не более чем на `Δ`. Меняя последнюю уступку, получаем n_points точек Парето.

### Как работает

1. Находится безусловный минимум `funcs[0]` → `f0_star`.
2. Для промежуточных критериев `funcs[1..n-2]`: каждый минимизируется с цепочкой ограничений на все предыдущие (фиксированная уступка `delta_default = 50`), полученные минимумы запоминаются.
3. Для последнего шага `funcs[-1]`: варьируется уступка `delta_last` от 5 до 300 — получаем `n_points` разных Парето-точек.
4. **Малая Δ:** ограничение жёсткое, точка остаётся близко к предыдущим минимумам. **Большая Δ:** больше свободы, последний критерий улучшается.

### Ключевые строки

```python
n = len(funcs)
# Промежуточная цепочка с фиксированной уступкой
for k in range(1, n - 1):
    constraints.append({'type': 'ineq',
                        'fun': lambda x, fi=funcs[k-1], f=f_stars[k-1]:
                               delta_default - (fi(x) - f)})
    f_stars.append(funcs[k](minimize(funcs[k], ..., constraints=constraints).x))

# n_points точек: варьируем последнюю уступку
for d_last in np.linspace(5, 300, n_points):
    final_constraints = constraints + [{'type': 'ineq',
                                        'fun': lambda x, fi=funcs[-2], f=f_stars[-1]:
                                               d_last - (fi(x) - f)}]
    res = minimize(funcs[-1], [0.0, 0.0], method='SLSQP', constraints=final_constraints)
```

## Интерпретация результатов

Все три метода генерируют точки из **множества Парето** — решений, где нельзя улучшить один критерий без ухудшения другого:

- Точки вблизи **(6, 6)** — хорошо для f1, плохо для f2 и f3.
- Точки вблизи **(-4, -6)** — хорошо для f2, плохо для f1 и f3.
- Точки вблизи **(-7, 8)** — хорошо для f3, плохо для f1 и f2.
- Внутренние точки — компромисс между всеми критериями.
