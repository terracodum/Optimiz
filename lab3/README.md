# Лабораторная работа 3 — Условная оптимизация (Лагранж, Розен, Зойтендейк)

**Вариант 1**
- Функция: `f(x, y) = x² + y²`
- Ограничение: `φ(x, y) = 2x − y − 2 = 0`
- Точное решение: `x* = 0.8`, `y* = −0.4`, `f* = 0.8`

## lab3.py — главный файл

```python
def var1(x, y):
    return math.pow(x, 2) + math.pow(y, 2)   # целевая функция f = x² + y²

def phi(x, y):
    return 2 * x - y - 2                       # ограничение φ = 0

eps = 0.1                                       # точность для всех методов

rozen(var1, phi, eps)      # метод проекции градиента
lagrange(var1, phi, eps)   # метод множителей Лагранжа
zoutendijk(var1, phi, eps) # метод Зойтендейка
```

## rozen.py — метод проекции градиента Розена

```python
x, y = 1.0, 0.0     # начальная точка: лежит на ограничении φ(1,0) = 2−0−2 = 0
step = 0.1           # начальный шаг вдоль касательной
delta = 1e-6         # малое приращение для численного градиента
```

**Основной цикл (до 100 итераций):**

```python
gx = (func(x + delta, y) - func(x, y)) / delta   # ∂f/∂x численно
gy = (func(x, y + delta) - func(x, y)) / delta   # ∂f/∂y численно
```

```python
# Ограничение 2x − y − 2 = 0, нормаль [2, −1], касательная [1, 2]
# Проецируем градиент (gx, gy) на направление [1, 2]:
proj_s = (gx * 1 + gy * 2) / 5      # скалярное произведение / |[1,2]|²
sx, sy = proj_s * 1, proj_s * 2      # проекция-вектор (компонент градиента вдоль касательной)
```

```python
norm_s = math.sqrt(sx**2 + sy**2)
if norm_s < eps: break               # СТОП: в точке минимума градиент вдоль ограничения = 0
```

```python
nx, ny = x - step * sx, y - step * sy   # шаг в сторону антипроекции (убывание f)
```

```python
if func(nx, ny) >= func(x, y):   # шаг не улучшил — дробим шаг вдвое
    step /= 2
    if step < eps * 0.01: break  # шаг стал микроскопическим — выходим
    continue                     # повторить с уменьшенным шагом (x, y не обновляем)
```

```python
x, y = nx, ny    # принимаем новую точку
itter += 1
```

**Почему именно направление `[1, 2]`:** вектор `[1, 2]` ортогонален нормали `[2, −1]` к прямой `2x − y = 2`, значит движение вдоль него не нарушает ограничение.

## lagran.py — метод множителей Лагранжа

Минимизируем функцию Лагранжа: `L = f + λ·φ = x² + y² + λ(2x − y − 2)`

Необходимое условие экстремума: `∇L = 0`.

```python
x, y, lam = 1.0, 1.0, 0.0   # начальная точка и начальное λ
lr = 0.1                      # шаг градиентного спуска по (x, y, λ)
```

**Итерационный шаг (градиентный спуск по всем трём переменным):**

```python
dL_dx = 2*x + lam*2      # ∂L/∂x = ∂f/∂x + λ·∂φ/∂x = 2x + 2λ
dL_dy = 2*y + lam*(-1)   # ∂L/∂y = ∂f/∂y + λ·∂φ/∂y = 2y − λ
dL_dlam = 2*x - y - 2    # ∂L/∂λ = φ(x,y)  — это же условие φ = 0
```

```python
error = math.sqrt(dL_dx**2 + dL_dy**2 + dL_dlam**2)   # норма градиента
if error < eps: break                                    # СТОП: градиент мал
```

```python
x   -= lr * dL_dx      # x движется против градиента
y   -= lr * dL_dy      # y движется против градиента
lam += lr * dL_dlam    # λ движется ПО градиенту (двойственная задача)
```

**Сходимость:** метод сходится к точке (0.8, −0.4, −0.4) — это стационарная точка Лагранжиана, соответствующая условному минимуму `f`.

## zoidec.py — метод Зойтендейка

```python
x, y = 1.0, 0.0    # начальная точка на ограничении φ(1,0) = 0
step = 0.1
delta = 1e-6
```

```python
df_dx = (func(x + delta, y) - func(x, y)) / delta   # ∂f/∂x
df_dy = (func(x, y + delta) - func(x, y)) / delta   # ∂f/∂y
```

```python
sx, sy = 1.0, 2.0   # фиксированное допустимое направление [1, 2] вдоль ограничения
```

```python
# Выбираем знак: движемся туда, где f убывает
if (df_dx * sx + df_dy * sy) > 0:
    sx, sy = -sx, -sy    # скалярное произведение > 0 → направление роста → берём противоположное
```

```python
nx, ny = x + step * sx, y + step * sy   # пробный шаг

if func(nx, ny) > func(x, y):   # не улучшили
    step /= 2
    if step < eps: break
    continue

x, y = nx, ny   # принимаем точку
```

**Почему `[1, 2]` сохраняет ограничение:** для линейного ограничения `2x − y = 2` вектор касательной — ровно `[1, 2]`. Движение строго вдоль него гарантирует `φ(новая_точка) = 0`.

**Отличие от Розена:** Розен вычисляет проекцию градиента численно на каждом шаге; Зойтендейк использует одно фиксированное направление и только проверяет его знак.
