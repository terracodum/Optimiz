# Лабораторная работа 3 — Условная оптимизация

Три метода условной оптимизации: минимизация `f(x, y)` при ограничении равенства `φ(x, y) = 0`.

Все методы принимают произвольные функции `func` и `phi` — производные вычисляются численно.

**Вариант 1 (пример запуска)**
- Функция: `f(x, y) = x² + y²`
- Ограничение: `φ(x, y) = 2x − y − 2 = 0`
- Точное решение: `x* = 0.8`, `y* = −0.4`, `f* = 0.8`

---

## lab3.py — главный файл

```python
def var1(x, y):
    return math.pow(x, 2) + math.pow(y, 2)

def phi(x, y):
    return 2 * x - y - 2

eps = 0.1

rozen(var1, phi, eps)
lagrange(var1, phi, eps)
zoutendijk(var1, phi, eps)
```

Чтобы передать другую функцию — просто замени `var1` и `phi`.

## rozen.py — метод проекции градиента Розена

### Идея

Движемся вдоль поверхности ограничения `φ = 0`, проецируя антиградиент `f` на касательную к этой поверхности. Таким образом каждый шаг уменьшает `f` и при этом не нарушает ограничение.

### Как работает

1. Начинаем с точки, лежащей на ограничении: `φ(x₀, y₀) = 0`.
2. На каждой итерации вычисляем градиент `f` численно: `(gx, gy)`.
3. Вычисляем нормаль к `φ = 0` — это градиент `phi`: `(dpx, dpy)`.
4. Касательная к `φ = 0` перпендикулярна нормали: `t = (−dpy, dpx)`.
5. Проецируем градиент на касательную: `s = (g · t / |t|²) · t`.
6. Делаем шаг против проекции: `(x, y) -= step * s`.
7. Если `f` не убыла — дробим шаг вдвое и повторяем.
8. Останавливаемся, когда проекция мала (`|s| < eps`) — значит, достигнут минимум вдоль ограничения.

### Ключевые строки

```python
dpx = (phi(x + delta, y) - phi(x, y)) / delta
dpy = (phi(x, y + delta) - phi(x, y)) / delta
tx, ty = -dpy, dpx                              # касательная к phi=0
proj_s = (gx * tx + gy * ty) / (tx**2 + ty**2)
sx, sy = proj_s * tx, proj_s * ty
```

## lagran.py — метод множителей Лагранжа

### Идея

Вводим вспомогательную функцию Лагранжа: `L(x, y, λ) = f(x,y) + λ·φ(x,y)`. В точке условного минимума градиент `L` по всем трём переменным равен нулю. Применяем градиентный спуск одновременно по `x`, `y` и `λ`.

### Как работает

1. Задаём начальные `x, y, λ`.
2. Вычисляем частные производные функции Лагранжа численно:
   - `∂L/∂x = ∂f/∂x + λ · ∂φ/∂x`
   - `∂L/∂y = ∂f/∂y + λ · ∂φ/∂y`
   - `∂L/∂λ = φ(x, y)` (невязка ограничения)
3. Обновляем переменные:
   - `x` и `y` движутся против градиента (минимизация по `x, y`)
   - `λ` движется по градиенту (максимизация по `λ` — двойственная задача)
4. Останавливаемся, когда норма градиента `< eps` — найдена стационарная точка Лагранжиана.

### Ключевые строки

```python
df_dx   = (func(x + delta, y) - func(x, y)) / delta
dphi_dx = (phi(x + delta, y)  - phi(x, y))  / delta

dL_dx   = df_dx + lam * dphi_dx
dL_dy   = df_dy + lam * dphi_dy
dL_dlam = phi(x, y)

x   -= lr * dL_dx
y   -= lr * dL_dy
lam += lr * dL_dlam
```

## zoidec.py — метод Зойтендейка

### Идея

На каждом шаге выбираем допустимое направление — касательную к `φ = 0` — и двигаемся вдоль неё в ту сторону, где `f` убывает. Направление вычисляется из градиента `phi`, поэтому метод работает с любым ограничением.

### Как работает

1. Начинаем с точки на ограничении: `φ(x₀, y₀) = 0`.
2. Вычисляем градиент `f` численно.
3. Вычисляем касательную к `φ = 0` из градиента `phi`:
   - нормаль к `φ = 0` — это `(dpx, dpy)`
   - касательная — перпендикуляр к нормали: `(−dpy, dpx)`
4. Выбираем знак направления: если скалярное произведение `df · s > 0`, направление ведёт вверх — берём обратное.
5. Делаем шаг: `(x, y) += step * s`.
6. Если `f` не убыла — дробим шаг.
7. Останавливаемся, когда шаг стал меньше `eps` или перемещение ничтожно.

### Ключевые строки

```python
dpx = (phi(x + delta, y) - phi(x, y)) / delta
dpy = (phi(x, y + delta) - phi(x, y)) / delta
sx, sy = -dpy, dpx          # касательная к phi=0

if (df_dx * sx + df_dy * sy) > 0:
    sx, sy = -sx, -sy       # убеждаемся, что идём вниз
```

### Отличие от Розена

Розен **проецирует** антиградиент на касательную — учитывает крутизну спуска. Зойтендейк просто идёт **вдоль** касательной в нужную сторону, не масштабируя шаг по величине градиента. Розен сходится точнее, Зойтендейк проще.
