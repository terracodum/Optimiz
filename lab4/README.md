# Лабораторная работа 4 — Многокритериальная оптимизация (Парето)

**Вариант 1.** Три критерия вида `fi(x1, x2) = ai·(x1−bi)² + ci·(x2−di)²`:

| Критерий | a | b  | c | d  | Безусловный min |
|----------|---|----|---|----|-----------------|
| f1       | 2 | 6  | 3 | 6  | (6, 6)          |
| f2       | 3 | −4 | 1 | −6 | (−4, −6)        |
| f3       | 1 | −7 | 2 | 8  | (−7, 8)         |

Задача: построить множество Парето-оптимальных точек (10 штук) каждым методом.

---

## lab4.py — главный файл

```python
def f1(x): return 2*(x[0]-6)**2  + 3*(x[1]-6)**2   # критерий 1, min в (6, 6)
def f2(x): return 3*(x[0]+4)**2  + 1*(x[1]+6)**2   # критерий 2, min в (-4, -6)
def f3(x): return 1*(x[0]+7)**2  + 2*(x[1]-8)**2   # критерий 3, min в (-7, 8)
```

funcs = (f1, f2, f3)

## additive.py — метод аддитивной свертки

**Идея:** сворачиваем три критерия в один: `F⁰ = α1·f1 + α2·f2 + α3·f3 → min`.
Меняя веса αi (при условии α1+α2+α3=1, αi≥0) получаем разные Парето-точки.

```python
weights = [
    (1.00, 0.00, 0.00),   # минимизируем только f1 → точка (6, 6)
    (0.00, 1.00, 0.00),   # минимизируем только f2 → точка (-4, -6)
    (0.00, 0.00, 1.00),   # минимизируем только f3 → точка (-7, 8)
    (0.50, 0.50, 0.00),   # компромисс f1 и f2
    (0.50, 0.00, 0.50),   # компромисс f1 и f3
    (0.00, 0.50, 0.50),   # компромисс f2 и f3
    (0.33, 0.33, 0.34),   # равные веса — «центр» Парето
    ...                   # ещё 3 несимметричных набора
]
```

```python
for a1, a2, a3 in weights:
    F = lambda x, a1=a1, a2=a2, a3=a3: a1*f1(x) + a2*f2(x) + a3*f3(x)
    # Замыкание a1=a1 важно! Без него все lambda захватят последнее значение a1 из цикла.

    res = minimize(F, [0.0, 0.0], method='Nelder-Mead', ...)
    # Nelder-Mead — симплекс-метод, не требует градиентов, хорош для гладких функций.

    x = res.x        # найденная точка Парето
    points.append(x.tolist())
```

## discrim.py — дискриминационный метод

**Идея:** накладываем ограничения-уступки на f1 и f2 (`f1(x) ≤ lim1`, `f2(x) ≤ lim2`),
минимизируем f3. Меняя lim1 и lim2, получаем разные Парето-точки.

```python
# Ищем безусловные минимумы f1 и f2 (они = 0 в точках (6,6) и (-4,-6))
x1_min = minimize(f1, [0.0, 0.0], method='Nelder-Mead').x
f1_min = f1(x1_min)   # ≈ 0

x2_min = minimize(f2, [0.0, 0.0], method='Nelder-Mead').x
f2_min = f2(x2_min)   # ≈ 0
```

```python
# Варьируем ограничения: от жёстких (lim = min + 20) до мягких (lim = min + 500)
lim1_vals = np.linspace(f1_min + 20, f1_min + 500, n_points)
lim2_vals = np.linspace(f2_min + 15, f2_min + 300, n_points)
```

```python
for i in range(n_points):
    constraints = [
        {'type': 'ineq', 'fun': lambda x, l=lim1_vals[i]: l - f1(x)},
        # ineq → f(x) ≥ 0, т.е. lim - f1(x) ≥ 0 → f1(x) ≤ lim
        {'type': 'ineq', 'fun': lambda x, l=lim2_vals[i]: l - f2(x)},
    ]
    res = minimize(f3, [0.0, 0.0], method='SLSQP', constraints=constraints)
    # SLSQP — Sequential Least Squares Programming, поддерживает ограничения.
```

**Жёсткие lim:** минимизатор f3 вынужден искать точку с малыми f1 и f2 — компромисс.
**Мягкие lim:** ограничения не активны, минимизатор f3 уходит к (-7, 8).

## successive.py — метод последовательных уступок

**Идея:** последовательно оптимизируем критерии по приоритету f1 → f2 → f3.
На каждом следующем этапе добавляем ограничение: предыдущий критерий
не ухудшается более чем на Δ.

```python
# Этап 1: безусловный минимум f1
res1 = minimize(f1, [0.0, 0.0], method='Nelder-Mead')
f1_star = f1(res1.x)   # ≈ 0 (в точке (6, 6))
```

```python
for d1 in delta1_vals:   # 5 значений уступки Δ1 ∈ [5, 200]
    # Этап 2: минимум f2 при f1(x) - f1* ≤ Δ1
    c1 = [{'type': 'ineq', 'fun': lambda x, d=d1, f=f1_star: d - (f1(x) - f)}]
    res2 = minimize(f2, [0.0, 0.0], method='SLSQP', constraints=c1)
    f2_star = f2(res2.x)

    for d2 in delta2_vals:   # 2 значения уступки Δ2 ∈ [30, 120]
        # Этап 3: минимум f3 при f1-f1*≤Δ1 И f2-f2*≤Δ2
        c2 = c1 + [{'type': 'ineq', 'fun': lambda x, d=d2, f=f2_star: d - (f2(x) - f)}]
        res3 = minimize(f3, [0.0, 0.0], method='SLSQP', constraints=c2)
        points.append(res3.x.tolist())
# Итого: 5 × 2 = 10 точек Парето
```

**Малая Δ1** → ограничение жёсткое, x остаётся близко к min f1 → точка ближе к (6, 6).
**Большая Δ1** → свободы больше, f2/f3 могут быть значительно улучшены.

## Интерпретация результатов

Все три метода генерируют точки из **множества Парето** — набора решений,
где нельзя улучшить один критерий без ухудшения другого:

- Точки вблизи **(6, 6)** — хорошо для f1, плохо для f2 и f3.
- Точки вблизи **(-4, -6)** — хорошо для f2, плохо для f1 и f3.
- Точки вблизи **(-7, 8)** — хорошо для f3, плохо для f1 и f2.
- Внутренние точки — компромисс между тремя критериями.
