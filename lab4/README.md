# Лабораторная работа 4 — Штрафные и барьерные функции

Минимизация функции с ограничениями-неравенствами методами преобразования к безусловной задаче.

**Вариант 1**
- Функция: `f(x) = x₁² + x₂² + 4x₂ − 1`
- Ограничения: `x₁² + x₂ ≤ 0`,  `x₁ − 2x₂ ≤ 8`
- Старт: `(0.5, −1.5)`,  `ε = 0.05`
- Точное решение: `x* = (0, −2)`, `f* = −5`

> Безусловный минимум `∇f = 0` → `x₁=0, x₂=−2` лежит внутри допустимой области,
> поэтому условный минимум совпадает с безусловным.

---

## barrier.py — метод барьерных функций

### Идея

Метод **внутренней точки**: двигаемся строго внутри допустимой области. Барьерная функция `−ln(g_i(x))` уходит в `+∞` при приближении к границе `g_i → 0`, создавая "стену". Чем меньше `r`, тем слабее барьер и тем точнее решение.

### Как работает

1. Начинаем с допустимой точки (`g_i(x₀) > 0`).
2. На каждой итерации минимизируем: `P(x, r) = f(x) + r · Σ(−ln(g_i(x)))`.
3. Уменьшаем `r` в 10 раз (`r *= 0.1`).
4. Останавливаемся когда `|r · Σ(−ln(g_i))| < ε`.

### Ключевые строки

```python
def P(x, r=r):
    if any(gv <= 0 for gv in [g(x) for g in constraints]):
        return 1e10          # вышли за границу — огромный штраф
    return func(x) + r * sum(-np.log(gv) for gv in g_vals)

r *= decay   # r уменьшается → барьер ослабевает → решение точнее
```

## penalty.py — метод штрафных функций

### Идея

Метод **внешней точки**: можно начинать снаружи допустимой области. Штрафная функция `(max{0, −g_i(x)})²` равна 0 когда ограничение выполнено, и растёт при его нарушении. Чем больше `r`, тем сильнее штраф за нарушение.

### Как работает

1. Начинаем с любой точки.
2. На каждой итерации минимизируем: `P(x, r) = f(x) + r · α(x)`, где `α(x) = Σ(max{0, −g_i(x)})²`.
3. Увеличиваем `r` в 10 раз (`r *= 10`).
4. Останавливаемся когда `r · α(x) < ε`.

### Ключевые строки

```python
def alpha(x):
    return sum(max(0.0, -g(x))**2 for g in constraints)

def P(x, r=r):
    return func(x) + r * alpha(x)

r *= growth  # r растёт → нарушать ограничения всё дороже
```

## Отличия методов

| | Барьерный | Штрафной |
|---|---|---|
| Тип | Внутренняя точка | Внешняя точка |
| Старт | Строго внутри области | Любая точка |
| Параметр `r` | Убывает | Растёт |
| Граница | Никогда не пересекается | Может нарушаться |
| Применимость | Только `g_i ≥ 0` | `g_i ≥ 0` и `h_i = 0` |
